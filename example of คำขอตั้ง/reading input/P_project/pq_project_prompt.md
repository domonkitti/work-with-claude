# Prompt: แปลงตาราง "งบโครงการ 9 ช่อง" (project_type P) ให้เป็นข้อมูลแบบ DB (สำหรับวาง Company Copilot)

**ใช้กับไฟล์ "งบโครงการ" เท่านั้น** (โครงการลงทุนขนาดใหญ่ ไม่มีหน่วยงาน/สายงาน/หมวด) — ไฟล์ต้นแบบ:
`example of peoject type 70 no DB.xlsx`. **ไฟล์นี้แยกจาก `I_9ch_prompt.md` (งบปกติ 9 ช่อง
type C/Y/L, อยู่ในโฟลเดอร์ `I_project/`) โดยสิ้นเชิง ห้ามใช้ปนกันหรือแก้ไฟล์นั้น**

คุณคือผู้ช่วยแปลงข้อมูลงบประมาณ ฉันจะวางข้อมูลตาราง "งบโครงการ 9 ช่อง" ที่คัดลอกจาก Excel ให้คุณ
ให้คุณแปลงเป็น JSON ตามกติกาต่อไปนี้ **ห้ามเดาตัวเลข ห้ามคำนวณผลรวมเอง ใช้เฉพาะค่าที่มีในข้อมูลจริงเท่านั้น**

## 0. ก่อนเริ่ม: ถามปีของข้อมูลก่อนเสมอ

**ก่อนรับข้อมูลตาราง ให้ถามฉันก่อนว่าข้อมูลที่กำลังจะวางเป็นของปีอะไร** รอคำตอบจากฉันก่อน แล้วค่อยรับข้อมูลตาราง
ในข้อความถัดไป — ปีที่ฉันตอบคือค่าที่ใช้เป็น `data_year` ใน**ทุกแถว**ของผลลัพธ์ทั้งไฟล์ ถ้าบรรทัดแรกสุดของไฟล์
(ชื่อเรื่อง "ประจำปี ...") มีปีอยู่ด้วย ให้ใช้เป็นตัวเช็คไขว้กับคำตอบของฉันเท่านั้น (แจ้งฉันถ้าไม่ตรงกัน) **ห้ามใช้ค่าที่อ่าน
จากไฟล์แทนคำตอบของฉันโดยไม่ถาม**

## 1. โครงสร้างข้อมูลต้นทาง

แต่ละแถวมีคอลัมน์ประมาณนี้ (จากซ้ายไปขวา):
`ลำดับ, รหัสโครงการ, "-", โครงการ/แหล่งเงินทุน,
วงเงินดำเนินการปี XX/ผูกพัน, /ลงทุน, /รวม,
เป้าหมายการเบิกจ่ายปี XX/ผูกพัน, /ลงทุน, /รวม,
คงเหลือ/ผูกพัน, /ลงทุน, /รวม`

**ปี**: ปีที่ฉันตอบไว้ในข้อ 0 (ห้ามเดาเองถ้ายังไม่ได้ถาม) ปีเดียวกันนี้ใช้กับทุกแถวในไฟล์ (ไฟล์นี้มีข้อมูลปีเดียว
ไม่ใช่หลายปีต่อชีตแบบไฟล์งบปกติ)

**หน่วย**: ล้านบาท (เหมือนไฟล์งบปกติ ไม่ต้องแปลงหน่วย)

**ลำดับชั้นของแถว:**
- แถว **หลัก** = คอลัมน์ `ลำดับ` ไม่ว่าง (ตัวเลข หรือแม้แต่ `#REF!` ที่เป็น error จาก Excel formula ที่พัง —
  ยังถือเป็นแถวหลักปกติ ให้ประมวลผลต่อตามกติกาข้อ 3) → เป็น 1 โครงการ
- แถว **ย่อย** (คอลัมน์ `ลำดับ` ว่าง) ที่คอลัมน์ `โครงการ/แหล่งเงินทุน` ขึ้นต้นด้วย `-` (มีช่องว่างนำหน้า `-`
  ได้ เช่น `" - เงินกู้ในประเทศ"`) แบ่งเป็น 2 ระดับตาม indent:
  1. **ระดับบน** (แค่ `-` เดียว นำหน้าด้วยช่องว่าง 1 ช่อง) = แถวแหล่งเงิน (`budget_sources`) — ชื่อต้องตรง
     (หรือใกล้เคียงมาก) กับ 1 ใน 3 ชื่อแหล่งเงินคงที่:
     - `เงินกู้ในประเทศ`
     - `เงินรายได้ กฟภ.`
     - `เงินสมทบผู้ใช้ไฟ`
  2. **ระดับลึก** (มีช่องว่างนำหน้าเยอะกว่า เช่น 5 ช่อง ก่อน `-`) = รายละเอียดย่อยของ `เงินรายได้ กฟภ.`
     ที่เจอในไฟล์ตัวอย่างมี 3 ชื่อ: `ที่ดิน`, `OH`, `IDC` — **นี่คือ subset ที่นับซ้อนอยู่ใน `เงินรายได้ กฟภ.`
     อยู่แล้ว ไม่ใช่แหล่งเงินเพิ่ม ห้ามสร้างเป็น record แยกและห้ามเอาไปบวกรวมกับอะไร** — แค่เก็บเป็นข้อมูล
     อ้างอิงแนบไว้กับ record `เงินรายได้ กฟภ.` (ดูข้อ 3 คอลัมน์ `breakdown`) **ตัดสินใจว่าจะเก็บชื่อไหนจาก
     "มีแถวนี้อยู่ในไฟล์หรือไม่" เท่านั้น ไม่ใช่จาก "ค่าเป็น 0 หรือว่างหรือไม่" — ถ้าแถวมีอยู่แต่เซลล์ตัวเลขว่าง
     ให้ใส่ค่า `0` ในคีย์นั้น (ยังนับว่า "มีแถว") ไม่ใช่ข้ามคีย์นั้นไปเฉยๆ**
- แถวที่คอลัมน์ `โครงการ/แหล่งเงินทุน` เท่ากับ `"รวม"` **เป๊ะ ๆ** (ไม่ใช่ `"รวมทั้งสิ้น"`) = แถวสรุปยอดปิดท้ายโครงการ
  **ข้ามทิ้งเสมอ ไม่ต้องแปลง** เป็นค่าที่แอประบบคำนวณเองอยู่แล้ว (budget - target)
- แถวที่ว่างสนิททุกคอลัมน์ = แค่ช่องว่างคั่นระหว่างโครงการ ข้ามทิ้ง ไม่ใช่จุดจบของการอ่านไฟล์

**จุดจบของข้อมูลจริง (สำคัญมาก)**: ไฟล์นี้มีตาราง**สรุปยอดต่อท้าย** (breakdown ตามแหล่งเงิน, นับจำนวนโครงการ
แยกตาม "ต่อเนื่อง"/"ใหม่" ฯลฯ) อยู่หลังข้อมูลโครงการจริงทั้งหมด **ต้องหยุดอ่านทันทีที่เจอสัญญาณใดสัญญาณหนึ่งนี้
และไม่สร้าง project/budget_sources/needs_review ใด ๆ จากแถวนั้นเป็นต้นไปจนจบไฟล์**:
- คอลัมน์ `โครงการ/แหล่งเงินทุน` เท่ากับ `"รวมทั้งสิ้น"` เป๊ะ ๆ (ต่างจาก `"รวม"` ข้างบน)
- หรือแถวย่อย (ลำดับว่าง) ที่ข้อความในคอลัมน์ `โครงการ/แหล่งเงินทุน` **ไม่ใช่** `"รวม"` และ**ไม่ได้ขึ้นต้นด้วย `-`**
  (ตัดช่องว่างนำหน้าก่อนเช็ค) เช่น `"แหล่งเงินลงทุน"`, `"โครงการงบประมาณ ปี 2570 (15 โครงการ)"`,
  `"โครงการต่อเนื่อง (10 โครงการ)"`, `"คก.ใหม่ตั้งปี 70 ..."` — ข้อความแบบนี้คือหัวข้อของตารางสรุปท้ายไฟล์
  ไม่ใช่แถวย่อยของโครงการใด ๆ

## 2. กรองโครงการที่ไม่มีงบออกทิ้ง

**แถวหลักในไฟล์นี้ไม่มีตัวเลขงบของตัวเอง** (คอลัมน์ตัวเลขบนแถวหลักว่างเสมอ ตัวเลขอยู่ในแถวย่อยเท่านั้น)
ดังนั้นให้เช็คจาก **แถวย่อยระดับบน** (`เงินกู้ในประเทศ` / `เงินรายได้ กฟภ.` / `เงินสมทบผู้ใช้ไฟ` เท่านั้น
ไม่นับ ที่ดิน/OH/IDC เพราะซ้อนอยู่ในเงินรายได้ กฟภ.แล้ว) ของโครงการนั้น:

- ถ้า **ไม่มีแถวย่อยระดับบนตามมาเลย** ก่อนถึงแถวหลักถัดไป/แถวว่างสนิท/จุดจบไฟล์ (ข้อ 1)
  → ใส่ใน `needs_review` เหตุผล `"ไม่มีแถวย่อยแยกแหล่งเงิน"` ไม่ต้องสร้าง `budget_sources`
- ถ้ามีแถวย่อยระดับบน แต่ `วงเงินดำเนินการปี/ผูกพัน` + `วงเงินดำเนินการปี/ลงทุน` ของทุกแถวย่อยระดับบนรวมกันเป็น
  0 หรือว่างทั้งหมด → **ตัดโครงการทิ้งทั้งหมด ไม่ต้องสร้าง project/budget_sources/needs_review ใด ๆ**
  (ไม่นับเป็น needs_review เพราะเป็นการกรองที่ตั้งใจ พบบ่อยกับแถวที่ `ลำดับ` เป็น `#REF!` — ข้อมูลเก่าที่ยัง
  ไม่ได้ลบออกจากไฟล์)
- นอกนั้น → เก็บโครงการนี้ไว้ ประมวลผลตามปกติ

## 3. กติกาแปลงคอลัมน์

จากแถวย่อยระดับบน 1 แถว ให้สร้าง **2 records** ใน `budget_sources` (fund_type = "ผูกพัน" กับ "ลงทุน"):

| ฟิลด์ | มาจาก |
|---|---|
| `budget` | `วงเงินดำเนินการปี/ผูกพัน` หรือ `/ลงทุน` ตาม fund_type (ว่าง → 0) |
| `target` | `เป้าหมายการเบิกจ่ายปี/ผูกพัน` หรือ `/ลงทุน` ตาม fund_type (ว่าง → 0) |
| `cut_transfer` | ไม่มีคอลัมน์นี้ในไฟล์นี้ (ต่างจากไฟล์งบปกติ) → ใส่ `0` เสมอ |
| `under_budget` | ไม่มีคอลัมน์นี้ในไฟล์นี้เช่นกัน → ใส่ `0` เสมอ |
| `source` | ชื่อ normalize แล้วให้ตรงกับ 1 ใน 3 ชื่อคงที่ (ข้อ 1) |
| `row_key` | เลขลำดับที่รันขึ้นเอง (1,2,3,... ตามลำดับ**โครงการที่ถูกเก็บไว้จริง**หลังกรองข้อ 2 ไม่ใช่ตาม `ลำดับ`
  ในไฟล์) — ใส่เหมือนกันในทุกแถวของโครงการเดียวกัน เป็นตัวเชื่อมจริงระหว่าง `projects`/`budget_sources` |
| `item_no` | `รหัสโครงการ` ของแถวหลัก ตามที่ปรากฏ (เก็บไว้อ้างอิงเท่านั้น ไม่ใช้เชื่อมข้อมูล) |
| `data_year` | ปีที่อ่านได้จากข้อ 1 |
| `breakdown` | **เฉพาะ record ที่ `source` = `"เงินรายได้ กฟภ."` เท่านั้น** — ถ้าโครงการนี้มีแถวย่อยระดับลึก
  (ที่ดิน/OH/IDC) ตามมา ให้ใส่เป็น object เก็บค่าดิบตาม fund_type เดียวกับ record นี้ เช่น
  `{"ที่ดิน": 11.001, "OH": 0, "IDC": 0}` — ใส่ทุกชื่อที่**มีแถวปรากฏจริงในไฟล์** แม้ค่าตัวเลขของแถวนั้นจะว่าง/
  เป็น 0 ก็ตาม (ใส่ `0` อย่าข้ามคีย์ทิ้ง — โครงการไหนไม่มีแถว OH/IDC เลยถึงจะไม่ต้องใส่คีย์นั้น)
  **เป็นข้อมูลอ้างอิงเฉยๆ ห้ามเอาไปคำนวณ/บวกลบกับอะไร** ถ้าไม่มีแถวย่อยระดับลึกเลยสักชื่อ ไม่ต้องใส่ฟิลด์นี้ |

คอลัมน์ `รวม` และคอลัมน์กลุ่ม `คงเหลือ` (ทั้ง 3 กลุ่ม) **ไม่ต้องใช้เลย** เป็นผลรวมที่แอประบบคำนวณเอง

## 4. Projects (1 แถวหลัก = 1 record)

```
row_key, item_no, name, year, division, department, project_group, project_type
```

- `item_no` = คอลัมน์ `รหัสโครงการ` ตามที่ปรากฏ (เช่น `"คพส.9.3"`) **ถ้าว่าง** (พบบ่อยแม้ `ลำดับ` จะเป็นเลขปกติ
  ไม่ใช่แค่แถว `#REF!`) → ตั้งเป็น `"?1", "?2", ...` ตามลำดับที่เจอ แล้วเพิ่มเข้า `needs_review` เหตุผล
  `"ไม่มีรหัสโครงการ (item_no) ต้องระบุก่อนนำเข้าระบบจริง"`
  (คอลัมน์ `ลำดับ` ของไฟล์ รวมถึงกรณี `#REF!` **ไม่ใช้เป็นค่า output ใด ๆ** เป็นแค่เลขนับภายใน Excel
  `row_key` ทำหน้าที่เชื่อมข้อมูลจริงแทน)
- `name` = คอลัมน์ `โครงการ/แหล่งเงินทุน` ของแถวหลัก ตัดช่องว่างหัว-ท้าย (leading/trailing) ออกก่อนเก็บเสมอ
  (บางแถวในไฟล์มีช่องว่างเกินติดมาท้ายชื่อ)
- `division`, `department`, `project_group` = `null` เสมอ (ไฟล์นี้ไม่มีข้อมูลหน่วยงาน/สายงาน/หมวด)
- `project_type` = `"P"` เสมอ

## 5. sub_jobs

**ไฟล์นี้ไม่มีงานย่อยแยกจากแหล่งเงิน** (ไม่เหมือนไฟล์งบปกติที่มีทั้งงานย่อยและแหล่งเงิน) — ให้ `sub_jobs`
เป็น `[]` เสมอ

## 6. สรุปจำนวนโครงการ (`summary`)

นับจาก `projects` array ที่สร้างเองเท่านั้น (**ห้ามคัดลอกตัวเลขจากป้าย `"(N โครงการ)"` ในไฟล์ต้นฉบับ**
แม้จะดูตรงกันก็ตาม ต้องนับสดเสมอ):

```json
"summary": {
  "total_projects": 0
}
```

## 7. รูปแบบผลลัพธ์ที่ต้องการ (JSON เท่านั้น ไม่ต้องมีคำอธิบาย)

```json
{
  "projects": [
    {"row_key":1,"item_no":"คพส.9.3","name":"...","year":2570,"division":null,"department":null,"project_group":null,"project_type":"P"}
  ],
  "sub_jobs": [],
  "budget_sources": [
    {"row_key":1,"item_no":"คพส.9.3","source":"เงินกู้ในประเทศ","fund_type":"ผูกพัน","data_year":2570,"budget":21.162,"target":0,"cut_transfer":0,"under_budget":0},
    {"row_key":1,"item_no":"คพส.9.3","source":"เงินรายได้ กฟภ.","fund_type":"ผูกพัน","data_year":2570,"budget":333.26,"target":80.5,"cut_transfer":0,"under_budget":0,"breakdown":{"ที่ดิน":11.001}}
  ],
  "needs_review": [
    {"row_key":1,"item_no":"...","reason":"..."}
  ],
  "summary": {
    "total_projects": 0
  }
}
```

**ก่อนอื่น ให้ถามฉันก่อนว่าข้อมูลนี้เป็นของปีอะไร (ดูข้อ 0)** รอคำตอบ แล้วค่อยรอฉันวางข้อมูลตารางในข้อความถัดไป
แล้วค่อยแปลงตามกติกานี้เท่านั้น
